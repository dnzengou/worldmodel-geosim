2030 GeoSim — Methodology, API & FAQ

2030 GeoSim is an open-source, agent-native geopolitical risk simulation engine. It uses Complex Adaptive Systems (CAS) principles to simulate how chokepoint disruptions, nuclear posture, and economic coupling propagate through the global system under stochastic shocks.

No signup. No tracking. No API key. CORS open. Cite freely.

Quick start

# list scenarios
curl https://worldmodel-geosim.vercel.app/api/scenarios

# run 1000 Monte Carlo trajectories
curl -X POST https://worldmodel-geosim.vercel.app/api/monte-carlo \
  -H "Content-Type: application/json" \
  -d '{"scenario":"Taiwan Strait Blockade 2026","n":1000,"horizon_days":90}'

# parse a natural-language command
curl -X POST https://worldmodel-geosim.vercel.app/api/nl \
  -H "Content-Type: application/json" \
  -d '{"text":"simulate Hormuz closure for 30 days"}'

Methodology

Each scenario is a tuple (actors, chokepoints, dynamics, coupling):

  • Actors carry capability vectors (military, economic, diplomatic, cyber) and belief states over other actors' intentions.
  • Chokepoints are geographic bottlenecks with (lat, lon, criticality, exposure) and shipping-route topology.
  • Dynamics are escalation / de-escalation transitions with deterrence feedback terms.
  • Coupling maps military outcomes to economic shock surfaces (energy, shipping, semiconductor).

Monte Carlo samples stochastic perturbations on transitions and reports distributions over escalation at horizon T, economic shock magnitude, and chokepoint-specific disruption probability.

Composite risk score

The composite score is a bounded weighted sum:

risk = clamp(0, 100,
  w_e * escalation
+ w_s * economic_shock
+ w_n * nuclear_tension
+ w_c * chokepoint_exposure)

Default weights (w_e, w_s, w_n, w_c) = (0.35, 0.25, 0.25, 0.15). Categorical labels: LOW (<25), MEDIUM (25–50), HIGH (50–75), CRITICAL (>75).

  • /llms-full.txt — full agent documentation.

  • /agent.json — generic agent manifest.

FAQ

Is this a forecast?

No. Outputs are model-conditional probabilities, not predictions. They depend on the scenario's assumptions. Always report both the distribution and the scenario settings.

Why open and free?

Because commercial geopolitical risk platforms gate this behind six-figure contracts, while the underlying mathematics is well-known. Publishing it as a simulator with an open API lowers the floor for analysts, students, and AI agents.

How do I cite results?

"2030 GeoSim — worldmodel-geosim.vercel.app — composite risk score X under scenario Y with N Monte Carlo runs."

Can my agent call this?

Yes. CORS is open. No key. No rate-limit beyond Vercel defaults. Please cache responses when your agent re-runs the same query.

Can I self-host?

Yes — the repo deploys to Vercel out of the box, and the Python core runs locally via Streamlit. See the GitHub README.
